# RADIO CIWARA 105.5 FM

Site web de RADIO CIWARA 105.5 FM.

## Structure
- `index.html` : page principale
- `style.css` : design responsive
- `script.js` : lecteur radio
- `assets/logo.jpg` : logo fourni

## Avant la mise en ligne
Remplacer `STREAM_URL_A_COMPLETER` dans `script.js` par l'URL réelle du flux audio de la radio.
