Sécurité & publication

Sauvegarde & publication

Exportez votre configuration, restaurez une sauvegarde ou ouvrez les fichiers du dépôt pour publier vos modifications.

Important : enregistrer ici ne modifie pas directement les fichiers GitHub. Téléchargez la configuration JSON puis remplacez data/radio-page-config.json dans le dépôt. Les visiteurs verront les changements une fois le déploiement terminé.

Exporter la configuration

Crée un fichier contenant les blocs, les émissions, les horaires et les paramètres visuels.

Gardez une copie de sauvegarde avant toute modification importante.

Importer une configuration

Chargez un fichier JSON exporté depuis cette administration.

L’import remplacera la configuration actuellement ouverte dans cet outil.

Publier sur GitHub

Le site public est hébergé sur GitHub Pages.

  1. Téléchargez radio-page-config.json avec le bouton d’export.
  2. Ouvrez le dossier data de votre dépôt GitHub.
  3. Créez ou remplacez radio-page-config.json par le fichier exporté.
  4. Validez le changement, puis attendez la fin du déploiement GitHub Pages.
  5. Rechargez radio.html pour vérifier le résultat.
